Understand, Exploit, and Prevent Cross-Site Scripting (XSS)

XSS is one of the most critical vulnerabilities on the web. It occurs when a web application processes untrusted user inputs and renders them into web pages without proper validation, sanitization, or encoding. Explore how attacker scripts bypass sandbox controls, and learn how to defend your applications.

Core XSS Vulnerabilities Covered

📡

Reflected XSS

User input is reflected by the server-side application response immediately, executing scripts contextually inside the victim's session. Frequently found in searches and error pages.

💾

Stored XSS

The malicious script is saved permanently in a database, log file, or cache. It executes whenever any user fetches the affected record. Highly dangerous.

🌐

DOM-based XSS

Vulnerability entirely resident in client-side script execution. Dynamic input is processed unsafely using dynamic execution sinks (`innerHTML`, `eval`) within the DOM.

Status: Vulnerable Mode — Input is echoed back to the screen unsanitized.
